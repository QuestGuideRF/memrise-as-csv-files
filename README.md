# Memrise Community Course Downloader v9.3

Это расширение для **Google Chrome** скачивает списки слов из **[курсов сообщества Memrise](https://community-courses.memrise.com/community/courses/)** в виде таблиц «.csv» вместе со всеми связанными изображениями, **аудио** и видео, **альтернативными ответами** и **прогрессом обучения**. Курсы можно [скачивать пакетами](https://github.com/Eltaurus-Lt/CourseDump2022?tab=readme-ov-file#batch-download). Формат сохранённых данных подходит для последующего [импорта](https://github.com/Eltaurus-Lt/Anki-Card-Templates?tab=readme-ov-file#the-support-add-on) в **[Anki](https://apps.ankiweb.net/)**.

Расширение *не* скачивает слова, которые вы пометили как «игнорируемые» в Memrise (сайт не отдаёт их в запросах). Перед загрузкой можно снять игнор или завести отдельный новый аккаунт Memrise, если данные о прогрессе не нужны.

## Установка

1. Скачайте архив и распакуйте в любое место на диске.
2. В *Google Chrome* нажмите кнопку `Расширения` , затем
  (либо откройте главное меню в правом верхнем углу и выберите `Расширения` → `Управление расширениями`)
3. Включите `Режим разработчика` (правый верхний угол страницы)
4. Нажмите `Загрузить распакованное` (левый верхний угол) и укажите папку распакованную на шаге 1
5. (*по желанию*) Снова нажмите кнопку `Расширения` из шага 2 и закрепите расширение на панели инструментов

#### Проверка результата

Для удобства к имени скачанного файла «.csv» и папки «...media» в скобках добавлены числа: всего скачанных элементов (слов) и число упомянутых медиафайлов.

Если в имени таблицы только одно число, например «...(123).csv», все элементы (**кроме игнорируемых**) сохранены. Если число не совпадает с тем, что на странице Memrise, оба значения показываются, например «...(42 из 58).csv» — загрузка неполная; стоит проверить сеть и повторить.

Memrise показывает ожидаемое число только если курс уже начат или не разбит на уровни. Иначе в имени «.csv» будет число по отсканированным уровням с тильдой, например «...(~77).csv». Чтобы убедиться, что всё скачано, сравните с независимой оценкой (проще всего — записаться на курс кнопкой «Get started now», ответить на пару вопросов, чтобы активировался счётчик, и снова посмотреть число на странице курса).

Для медиа сравните число в конце имени папки «...media» с реальным числом файлов внутри. Если не совпадает — часть файлов могла не скачаться из‑за сети (у вас или на сервере Memrise). Чаще всего помогает повторная загрузка. Удалять файлы после неудачных попыток не нужно: расширение кладёт файлы в ту же папку и разрешает конфликты имён — при нестабильной сети несколько частичных попыток могут дать полный набор медиа.

В редких случаях в курсе есть ссылки на несуществующие файлы. При битой ссылке полоса может стать красной, а ошибка появится на странице «Управление расширениями».

## 💡 Импорт в Anki

> кратко (минимальный импорт):
>
> 1. Создайте тип записей:
>   1. Откройте скачанный «.csv» → посмотрите число и названия столбцов
>   2. В Anki: `Инструменты` (меню слева вверху) → `Управление типами записей` → `Добавить` → `Добавить: Basic` → имя (например, «Memrise — японский») → `OK` → `Поля` → добавьте/переименуйте поля под столбцы из «.csv» (столбец «Level tags» не нужен) → `Сохранить` → закройте окно
> 2. Создайте колоду: `Создать колоду` (внизу по центру главного экрана) → имя курса → `OK`
> 3. Импорт таблицы: `Файл` → `Импорт` → выберите «.csv» → `Открыть` → укажите `Тип записей` и `Колоду` в разделе параметров импорта → `Импорт` (справа вверху) → дождитесь окончания → закройте окно
> 4. Перенесите медиа (если есть): `Инструменты` → `Проверить медиа` → `Просмотр файлов` (слева внизу) → скопируйте все файлы **изнутри** папки «...media» курса в открытую папку «collection.media» → закройте окна

### 1. Выбор типа записей

*Типы записей* — по сути аналог шаблонов базы Memrise в Anki (настройки курса и шаблоны карт внутри). Важно подготовить **шаблон с достаточным числом полей под все столбцы** (остальное можно править позже). Столбцы курса видны в «.csv» в строке, начинающейся с «#columns:».

Варианты:

1. [Создать новый тип записей](https://docs.ankiweb.net/editing.html#adding-a-note-type), добавив нужное число полей:
  1. `Инструменты` → `Управление типами записей`
  2. `Добавить` → `Добавить: Basic` (или клонировать другой шаблон)
  3. Имя, например «Memrise — немецкий» (для нескольких курсов на одном языке можно один тип — так проще управлять картами) → `OK`
  4. `Поля` → `Добавить`, пока не хватит столбцов из «.csv» (столбец «Level tags» особый, отдельное поле для импорта не нужен). Имена полей и столбцов могут различаться, но лучше совпадать. Переименование: выделить поле → `Переименовать` → в конце `Сохранить` и закрыть окно
    бы **видеть поле при повторении**, отредактируйте **шаблоны карт** и вставьте поле на нужную сторону (см. [руководство Anki](https://docs.ankiweb.net/templates/intro.html); вопросы — на [форуме](https://forums.ankiweb.net/)).
2. Использовать **[шаблон Memrise](https://github.com/Eltaurus-Lt/Anki-Card-Templates?tab=readme-ov-file#memrise)** — повторяет оформление и большую часть функций Memrise. По умолчанию пять полей: «Learnable», «Definition», «Audio» и два дополнительных. Как добавить поля и переименовать — в [разделе настройки](https://github.com/Eltaurus-Lt/Anki-Card-Templates?tab=readme-ov-file#customization).
3. Для минимальных данных (learnable + definition) подойдёт любой тип, в том числе стандартный «Basic» без правок.
  С медиа (аудио и видео) можно использовать шаблоны из папки расширения — «Basic (with media)», «Basic (and reversed card with media)», «Basic (reading, writing, and listening)» — они отличаются типами вопросов. Импорт шаблонов:
  1. Дважды щёлкните `Anki Templates.apkg` в папке (или в Anki: `Файл` → `Импорт` → выберите `.apkg`)
  2. Появится пример колоды с тремя картами — её можно сразу удалить, если не нужна.
    работки шаблонов — по пункту 1 выше.
4. Шаблоны ищут по интернету; старт — [AnkiWeb](https://ankiweb.net/shared/decks?search=template).

### 2. Создание колоды (по желанию)

1. Внизу главного экрана нажмите `Создать колоду`:
2. Введите название курса (можно скопировать из скачанного `info.md`) → `OK`
3. Описание курса из того же `info.md` можно вставить как описание колоды:
  1. Откройте колоду по названию
  2. Внизу экрана нажмите `Описание`
  3. Скопируйте текст в открывшееся окно
4. Для миниатюры можно использовать [это дополнение](https://github.com/Eltaurus-Lt/Lt-Anki-Addons/tree/main/Lstyle) и картинку из папки курса.

Колоды можно вкладывать друг в друга (перетаскиванием), группируя по языку/теме или уровням. Поиск по тегам в Anki работает и без отдельной колоды на каждый курс.

### 3. Импорт таблицы

1. `Файл` → `Импорт`
2. Укажите «.csv» в [папке скачанного курса](https://github.com/Eltaurus-Lt/CourseDump2022?tab=readme-ov-file#-downloading-a-memrise-course) → `Открыть`
3. Проверьте таблицу в разделе «Файл» и задайте `Тип записей` и `Колоду` в «Параметры импорта»:
4. Пролистайте вниз до «Сопоставление полей». Здесь задаётся соответствие полей Anki и столбцов Memrise. Совпадающие имена сопоставятся сами; остальное — вручную справа. Столбцы без полей при импорте пропускаются.
5. `Импорт` справа вверху. После обработки откроется отчёт; в «Обзор» — общее число импортированных записей:
  Сравните с [общим числом элементов курса](https://github.com/Eltaurus-Lt/CourseDump2022?tab=readme-ov-file#checking-download-results). В «Подробности» — информация по каждой записи.
    Карты можно смотреть в `Обзор` (меню по центру вверху), выбрав колоду слева:

### 4. Перенос медиафайлов

1. Чтобы открыть папку «collection.media», куда Anki кладёт медиа: `Инструменты` → `Проверить медиа` → `Просмотр файлов` (слева внизу)
  Пути по умолчанию для ручного открытия:
  ```
    * Windows: `%APPDATA%\Anki2\[имя пользователя Anki]\collection.media`
    * Mac: `~/Library/Application Support/Anki2/[имя пользователя Anki]/collection.media` (папка Library скрыта; в Finder: удерживайте Option при меню «Переход»)
    * Linux: `~/.local/share/Anki2/[имя пользователя Anki]/collection.media` для обычной установки или `~/.var/app/net.ankiweb.Anki/data/Anki2/[имя пользователя Anki]/collection.media` для Flatpak
  ```
2. Переместите все файлы из подпапки «...media» курса в «collection.media». Переносите **сами файлы**, **[не подпапку](https://docs.ankiweb.net/importing.html#importing-media)**.
  После переноса закройте и снова откройте `Инструменты` → `Проверить медиа`. Если нет пропущенных и лишних файлов по импортированному курсу — всё в порядке.

## Настройки

### Основные

Основные настройки

1. **Скачивать медиа**: скачивает изображения, аудио и видео из курса и вставляет ссылки в таблицу
2. **Прогресс обучения**: сохраняет ваш прогресс в Memrise в формате, совместимом с [дополнением для импорта](https://github.com/Eltaurus-Lt/Anki-Card-Templates?tab=readme-ov-file#the-support-add-on)
3. **Дополнительные поля**: все поля курса (часть речи, пример предложения, транскрипция, буквальный перевод и т.д.). Подписи — в «.csv». Если выключить, останутся базовые: «Learnable», «Definition», «Audio», «Video», «Tags» (последние три можно отключить отдельными настройками)
4. **Альтернативные ответы**: добавляет скрытые и явные альтернативы в ячейки; формат как в [шаблоне и дополнении](https://github.com/Eltaurus-Lt/Anki-Card-Templates?tab=readme-ov-file#formatting-alternative-answers)
5. **Теги уровней**: дополнительный столбец со структурой уровней Memrise в виде `course_name::level##`; при импорте в Anki превращается в [иерархические теги](https://docs.ankiweb.net/editing.html#using-tags)
6. **Подсказка импорта в Anki**: после каждой загрузки открывает это readme. Если вы уже здесь — можно отключить

### Дополнительно

Дополнительные настройки

1. **Метаданные курса**: помимо таблицы и медиа скачиваются `info.md` с описанием, обложка курса и аватар автора. Если выключено, «.csv» и папка медиа попадают прямо в загрузки Chrome, без отдельной папки курса с метафайлами
2. **ID элементов**: дополнительный столбец с уникальным id каждого элемента — для поиска дубликатов в Anki (например, через [поле сортировки](https://docs.ankiweb.net/editing.html#customizing-fields)) или связи с другими данными Memrise, например [архивом мемов](https://github.com/Eltaurus-Lt/MemDump)
3. **Метаданные элементов**: технические данные для удобства в Anki с [дополнением поддержки](https://github.com/Eltaurus-Lt/Anki-Card-Templates?tab=readme-ov-file#the-support-add-on): направления тестов по уровням, готовые варианты для тестов с выбором ответа
4. **Видеофайлы**: можно исключить видео из загрузки: при выключении переопределяет «Скачивать медиа» только для видео; картинки и аудио не трогает (если «Скачивать медиа» выключено — эффекта нет)
5. **Пропустить загрузку медиа**: на этапе файлов не качает медиа, но столбцы в таблице оставляет (в отличие от полного отключения «Скачивать медиа»). Удобно пересобрать таблицу с другими настройками без повторной загрузки всей папки медиа
